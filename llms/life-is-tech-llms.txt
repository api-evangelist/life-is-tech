# Life is Tech

> Life is Tech, Inc. (ライフイズテック株式会社) is a Tokyo-based education technology company,
> founded 6 July 2010 by Yusuke Mizuno, that teaches digital, programming and AI skills to
> Japanese teenagers, schools, municipalities and employers. It is a certified B Corporation
> (October 2022) and holds the Japanese PrivacyMark. Life is Tech sells finished learning
> products — camps, schools, cloud curriculum and corporate training — and publishes NO public
> API, SDK, webhook surface, developer portal or machine-readable contract of any kind.
> This file was generated by API Evangelist from the company's own public pages; it is a
> third-party profile, not a company-published document.

## Products

- [Life is Tech ! (camps and schools)](https://camp.life-is-tech.com/): Programming and AI camps and
  year-round schools for junior and senior high school students in Japan.
- [Life is Tech ! Lesson](https://lifeistech-lesson.jp/): Cloud-based information and programming
  curriculum used by roughly 4,000 public and private schools across some 600 municipalities.
- [Life is Tech ! Lesson for juku](https://juku.lifeistech-lesson.jp/): The same curriculum packaged
  for cram schools.
- [Life is Tech ! Leaders](https://leaders.life-is-tech.com/): Leadership and engineering development
  program for university students.
- [Life is Tech ! Career](https://career.life-is-tech.com/): Digital and AI job-hunting support for
  university students.
- [DX Readiness](https://dx.life-is-tech.com/): Digital-transformation skills training for corporate
  employees.
- [Municipal programs](https://project.life-is-tech.com/forlocal/): Digital talent development run
  with local governments.

## API surface

There is none. As of 2026-08-25 API Evangelist probed every public Life is Tech host —
life-is-tech.com, camp., dx., leaders., career., members., project., jobs.life-is-tech.com,
lifeistech-lesson.jp and juku.lifeistech-lesson.jp — for `/openapi.json`, `/openapi.yaml`,
`/swagger.json`, `/v1/openapi.json`, `/api-docs`, `/docs`, `/redoc`, `/graphql`, `/llms.txt`,
`/.well-known/security.txt`, `/.well-known/openid-configuration`,
`/.well-known/oauth-authorization-server`, `/.well-known/api-catalog`, `/.well-known/ai-plugin.json`,
`/.well-known/agent-card.json` and `/.well-known/agent.json`. Every path missed. Several hosts are
single-page-app catch-alls that answer HTTP 200 with an HTML shell for any path, including a random
control path; those 200s are soft-404s and are recorded as misses, not documents. No OpenAPI,
AsyncAPI, GraphQL SDL, Protobuf, WSDL, MCP server, A2A agent card, Postman collection, SDK or
package-registry client library was found on any host or in any registry (npm, PyPI, RubyGems).
See `well-known/life-is-tech-well-known.yml` in this repository for the full probe record.
